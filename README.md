# 🚀 Git Commit Helper

Интерактивная CLI-утилита для создания правильных git-коммитов по стандарту **Conventional Commits**.

## 📋 Что это?

Git Commit Helper анализирует ваши изменения в git и помогает создать правильное сообщение коммита автоматически. Больше не нужно думать, как правильно оформить коммит!

## ✨ Возможности

- 🔍 **Автоматический анализ изменений** — определяет добавленные, изменённые и удалённые файлы
- 🎯 **Умные предложения** — рекомендует тип коммита на основе изменений
- 📝 **Conventional Commits** — генерирует сообщения по стандарту
- 🎨 **Красивый интерфейс** — цветной вывод в терминале
- ⚡ **Интерактивность** — можно выбрать тип или отредактировать сообщение

## 🎯 Типы коммитов

| Тип | Описание |
|-----|----------|
| `feat` | Новая функциональность |
| `fix` | Исправление бага |
| `docs` | Изменения в документации |
| `style` | Форматирование кода (не влияет на работу) |
| `refactor` | Рефакторинг кода |
| `test` | Добавление тестов |
| `chore` | Обновление зависимостей, конфигурации |

## 📦 Установка

### Глобальная установка (рекомендуется)

```bash
npm install -g git-commit-helper
```

### Локальная установка в проект

```bash
npm install --save-dev git-commit-helper
```

## 🚀 Использование

После установки просто запустите в папке с git-репозиторием:

```bash
git-helper commit
```

### Пример работы

```bash
$ git-helper commit

🚀 Git Commit Helper

Обнаруженные изменения:
  + Добавлено: 2 файл(ов)
    - src/auth.js
    - src/middleware.js
  ~ Изменено: 1 файл(ов)
    - package.json

Рекомендуемый тип коммита: feat (новая функциональность)

Доступные типы:
  → feat: новая функциональность
    fix: исправление бага
    docs: изменения в документации
    style: форматирование кода
    refactor: рефакторинг
    test: добавление тестов
    chore: обновление зависимостей, конфигурации

Выберите тип (Enter = feat): 

Предлагаемое сообщение:
  feat: add src/auth.js, src/middleware.js

Использовать это сообщение? (y/n/edit): y

✓ Коммит успешно создан!
Сообщение: feat: add src/auth.js, src/middleware.js
```

## 🎮 Опции при создании коммита

- **Enter** — использовать предложенный тип коммита
- **Название типа** — выбрать другой тип (например: `fix`, `docs`)
- **y / yes** — подтвердить предложенное сообщение
- **n / no** — отменить коммит
- **edit / e** — отредактировать сообщение вручную

## 🔧 Требования

- Node.js >= 14.0.0
- Git установлен и настроен

## 📚 Больше о Conventional Commits

Conventional Commits — это стандарт для написания сообщений коммитов. Он помогает:

- 📊 Автоматически генерировать CHANGELOG
- 🔍 Легко искать в истории изменений
- 🤖 Автоматизировать релизы и версионирование
- 👥 Поддерживать единый стиль в команде

Подробнее: [conventionalcommits.org](https://www.conventionalcommits.org/)
